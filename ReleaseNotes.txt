v3.0.0
22 November 2026
  New features
  - Offline mode: a whole songbook can be saved for offline use; a status dot and popup show how much is cached.
  - The app now switches pages without full reloads; the header, footer and audio player stay in place.
  - Audio:
    - New "All audio" page and per-singer pages, with sorting and a collapsible singer list.
    - New player bar at the bottom of the screen that keeps playing while you move between pages; previous/next and auto-play of the next track.
    - Improved inline player on song pages; SoundCloud support.
    - New recordings by Manasa Krishna Prabhu and Kamal Krishna Prabhu (en songbook); improved singer ordering.
    - Clearer audio labels; audio can be filtered by title for specific songbooks.
  - New "Other songbooks" page for less-used songbooks.
  - Songbooks can include text pages besides songs, with a new look for the contents page.
  - Images in songs and pages (lazy loaded); small images stay visible when the translation is hidden.
  - Songbook HTML export page, with an option to hide translations.
  - Analyze songbooks page (a table of each songbook's data).
  - New English songbook.
  - Authors page: "Unknown author" section showing first lines; songs sorted per author.
  - A–Z index: similar diacritic letters are grouped together.
  - A song can appear several times in the index; page numbers can be overridden.
  - Song headings support line breaks; verse separators.
  - Other translations: the list is hidden when there is only one translation and shown as disabled when there are none.
  - Telegraph link in the share form.
  - Learn mode: better word splitting (apostrophes as separators), tuned font and content width, mobile verse sizes.
  - Improved search engine visibility: structured data for songs, audio and pages, better titles, previews and sitemap; old .html URLs redirect to their current address.
  - Updated analytics events.

  Fixes
  - Previous/next navigation for songs listed twice on the same page.
  - Footer navigation stays reachable while the player bar is shown.
  - Playback keeps following the playlist where Play was pressed; the player bar title links back to that page and its sort order.
  - Search: numpad layout after a search starts; page number centering in results.
  - Song and image rendering; learn mode rendering.
  - Hidden verses with partial data; wide verse styles; long titles in the vertical footer.
  - Bold text and escaped asterisks; sorting of index lines with numbers; "no-author" no longer shown as an author.
  - Pages for duplicated content items.
  - Default icon on /favicon.ico; 404 for search bots on legacy .html paths.
  - Footnote button width on desktop; first verse margin; default translation font weight; spacing of learn verses without a number.
  - Links no longer open in a new tab.

  Internal
  - pnpm and Node 24; reviewed deployment.
  - Refactored songbook data format and URL generation.
  - Full test suite (Vitest + Playwright).
